BetterSoL (branded as SoL.gg) is a Next.js web application built for League of Legends players who want to improve their gameplay and understand the meta. Users can search for any summoner by Riot ID and view a detailed profile with match history, recent performance, champion stats, and role breakdowns pulled from the Riot Games API. The app also aggregates stored match data to surface champion insights such as pick rates, ban rates, win rates, and tier rankings for the current patch. A leaderboard page tracks high-elo players in Challenger, Grandmaster, and Master tiers. The long-term vision includes an AI coaching agent that teaches core skills like macro, micro, itemization, and laning to make studying the game feel easier.
